# Backstage 2027 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (Ida: alle etaper i loop). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backstage (admin.energida.dk) bygges op forfra efter spec'en `docs/superpowers/specs/2026-09-08-backstage-2027-design.md`: forsiden viser det, der venter, og fire døre; Kunderne, én kunde, Energida og Søg som egne fliseskærme.

**Architecture:** Alt bor i den ene fil `index.html` (admin og kundeapp er samme fil). Nye skærme er nye `#dside-*`-containere + én tegner-funktion pr. skærm; gamle skærme skjules med `data-arkiv`, aldrig slettes. Data hentes fra eksisterende tabeller (`content_ideer`, `kunde_opgaver`, `mr_rum`) via eksisterende `sb`-klient; ingen nye tabeller.

**Tech Stack:** Vanilla JS/CSS i index.html · Supabase JS (global `sb`) · testsele `.sele/byg-sele.py` + headless Chrome (390 og 1440) · deploy via `ENERGIDA_SECURITY_DEPLOY=1 git add|commit|push` (én kommando ad gangen), `APP_VERSION` + `version.txt` bumpes hver deploy, live-tjek `curl -s --compressed https://b2b.energida.dk/version.txt`.

## Global Constraints

- Ingen pile · ingen tal i cirkler · ingen beskrivende tekster · Poppins aldrig fed · rødt kun til handlinger og det, der venter · altid »Tilbage« (lang hvid knap nederst på telefonen) · sendefeltet (`sendFeltHtml`) alle steder, hvor man kan skrive noget til · fliser, aldrig rækker i én kasse · sorte titler med grå forklaring · Luk = kryds i lille cirkel på yderste rammes hjørne.
- Kun funktioner Ida bruger; det, der ikke bruges, får `data-arkiv="8/9"` + `display:none`.
- Ved mindste tvivl: fem bud som Artifact + klik, før der bygges.
- Aldrig køn, aldrig I/jer, kunder aldrig ved navn i tekster (personaer). Ordene »hængepartier«/»Hvad hænger« findes ikke.
- Hver etape: `node --check` på scriptet, sele-skærmbillede på 390 og 1440, deploy, live-tjek, notat i manual (html+pdf), skill og hukommelse.
- Bevægelse: `transform:scale(.97)` 160 ms `cubic-bezier(0.23,1,0.32,1)` på fliser; intet andet animerer; `prefers-reduced-motion` respekteres.
